# v0.3.2 验证记录

日期：2026-11-20。

- 用户反馈轴用 40 mm 的卡簧槽尺寸缺失，并要求以最新国标为准。
- 官方题录确认 GB/T 894-2017 仍为现行；上次复审 2025-07-01，结论继续有效。官方题录：https://std.samr.gov.cn/gb/search/gbDetailed?id=71F772D817CED3A7E05397BE0A0AB82A 。
- 已直接打开官方全文公开系统在线预览，核对表 1 正文第 4 页（在线预览第 6/16 页）：轴用 40 mm 槽径基本尺寸仍为 37.0 mm，偏差 0 / -0.25 mm，表列名义槽深 1.25 mm，槽宽 1.85 H13，最小边距 3.8 mm。官方全文：https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=E059CDBC519BE5EDDD4C5A122F76F15B 。
- 现行国标表列槽径与槽深关系不一致：(40-37)/2=1.5 mm，与表列 1.25 mm 不同。东波、Rotor Clip 等厂家资料列槽径 37.5 mm，但本次遵照用户要求，不以厂家值改写国标表列值，也不声称取得了官方勘误。
- 界面与复制内容恢复显示原表槽径、数值偏差、极限尺寸、槽深；单独显示醒目的核对提示。该行沟槽示意仍暂停绘制。其他 173 条尺寸不变，孔用 40 mm 不受影响。

- 核心检查 2056 项通过；Release 构建 0 个警告、0 个错误；完整便携版与精简版均发布编译成功。
