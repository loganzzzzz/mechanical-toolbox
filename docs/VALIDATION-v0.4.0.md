# v0.4.0 验证记录

日期：2026-11-20。

用户要求所有模块统一采用最新现行国标，并选择键槽仅手动选择国标截面，轴径仅用于计算检验尺寸。

- 来源及原表审查详见 [NATIONAL-STANDARDS.md](NATIONAL-STANDARDS.md)。覆盖 23 档螺栓（69 项通孔、23 项钻径、23 组 6H 极限）、20 档内六角头、26 档键槽及 174 档挡圈。核对后原标准尺寸数值一致；不以厂商、公式或 ISO 值改写国标。
- 通孔改用 GB/T 5277-1985，钻径改用 GB/T 20330-2006 表 1，6H 极限改用 GB/T 15756-2008 表 3；通孔/挡圈槽宽数值偏差改用 GB/T 1800.2-2020 表 1、6。增加 H14 的大于 1 mm 适用范围保护。
- 键槽结构升级为 v2，仅保存 GB/T 1095-2003 表 1 的截面、槽尺寸和公差；移除手册轴径推荐范围、推荐来源及对应旧接口。用户可选全部 26 档国标截面，改变轴径不会改变截面。
- 轴用 40 mm 保留原表数字与显著差异提示。全部查询页面、复制结果、CSV 代码接口和来源页同步为国标；来源页明确离线快照的核对日期，未声称自动跟踪未来标准变化。
